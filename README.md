# Sobre meu projeto 'Honkai Star Rail'

Projeto realizado para finalização do módulo ' Desenvolvimento Web' do curso de_Informática_ da Microcamp Barueri.

O projeto teve por finalidade aplicar o que aprendido de HTML5 e CSS no módulo, doran utilizados

-tags semânticas
-estilização do site, utilizando cores, imagens ETC.
-Atributos

## Escolha do tema

O tema foi Honkai Star Rail porque eu gosto muito do Design do Jogo e da história, pois Amphoreus e a Aliança Xianzhou foram as minhas aventuras preferidas, pois me apeguei muito aos personagens, história, e ao design do jogo.
